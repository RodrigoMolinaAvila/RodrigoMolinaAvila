1. MATCH — patrones de grafo

Define el patrón a buscar en el grafo. Similar a WHERE en SPARQL.

MATCH (p:Person)-[:ACTED_IN]->(m:Movie) RETURN p.name, m.title

2. Etiquetas y propiedades

:Movie, :Person son etiquetas de nodo. {title: "Inception"} filtra por propiedad. m.title accede a propiedad.

MATCH (m:Movie {title: "Inception"}) RETURN m.genre

3. Relaciones y direcciones

-[:ACTED_IN]-> relación dirigida. <-[:DIRECTED]- dirección inversa. -[:FRIEND_OF]- sin dirección.

MATCH (p)-[r:ACTED_IN]->(m) RETURN r.role         # acceder a propiedad de la relación
MATCH (p)-[:FRIEND_OF]-(f)                          # bidireccional

4. WITH — pipeline

Pasa resultados entre partes de la consulta. Permite agregar, filtrar y renombrar variables.

MATCH (p)-[:ACTED_IN]->(m)
WITH m, COUNT(p) AS n WHERE n > 2 RETURN m.title

5. WHERE — filtros

Filtra resultados. Soporta operadores: >, <, =, <>, IN, NOT, AND, OR, EXISTS.

WHERE n > 2 AND m.title <> "Inception"
WHERE NOT p.name IN ["Tom", "Jerry"]

6. Agregación: COUNT, COLLECT

COUNT cuenta resultados. COLLECT agrupa en lista.

WITH p, COUNT(DISTINCT f) AS n_friends
WITH COLLECT(DISTINCT f.name) AS names

7. ORDER BY, LIMIT, DISTINCT

ORDER BY n_fr DESC LIMIT 3
RETURN DISTINCT name

8. Caminos de longitud variable

*1.. = uno o más saltos. *1..3 = 1 a 3 saltos. * = cero o más.

MATCH (p:Person {name:"Margot Robbie"})-[:FRIEND_OF*1..]-(f:Person)

9. UNWIND

Expande una lista en filas individuales. Útil tras COLLECT para deduplicar.

WITH COLLECT(DISTINCT f.name) AS names UNWIND names AS n RETURN DISTINCT n
