1. ¿Qué es SHACL?

SHApes Constraint Language es un lenguaje para validar grafos RDF contra un conjunto de condiciones (shapes). A diferencia de OWL (que infiere conocimiento nuevo), SHACL verifica que los datos cumplan restricciones.

Produce un reporte de validación: conforme (sh:conforms true) o lista de violaciones (sh:ValidationResult).

Clase 5, diapositivas 10-11: «SHACL permite validar datos RDF contra shapes. Produce un validation report.»

2. NodeShape y target

Un sh:NodeShape define restricciones para nodos. El sh:targetClass indica a qué instancias de clase se aplica.

ex:LaureateShape a sh:NodeShape ;
    sh:targetClass nobel:Laureate .

Otros targets: sh:targetNode (un nodo específico), sh:targetSubjectsOf (sujetos de una propiedad), sh:targetObjectsOf (objetos de una propiedad).

Clase 5, diapositiva 15: «Una shape puede targetear instancias de clase, nodos específicos, sujetos u objetos.»

3. sh:path y sh:datatype

sh:path indica la propiedad a validar. sh:datatype restringe el tipo de dato del valor.

sh:property [
    sh:path foaf:birthday ;
    sh:datatype xsd:date ;
]

Tipos comunes: xsd:string, xsd:date, xsd:integer, rdf:langString.

Clase 5, diapositiva 12: «Define una shape con sh:path y sh:datatype.»

4. sh:alternativePath

Permite aplicar una misma restricción a múltiples propiedades alternativas. Útil cuando varias propiedades comparten la misma regla.

sh:path [ sh:alternativePath (foaf:givenName foaf:name foaf:familyName) ] ;
sh:datatype xsd:string ;

El validador verifica la restricción contra todos los valores de cualquiera de las propiedades listadas.

5. Cardinalidad: minCount / maxCount

Restringen el número de valores para una propiedad.

sh:property [
    sh:path dbo:affiliation ;
    sh:minCount 1 ;     # al menos 1 valor
]

sh:minCount 0 hace la propiedad opcional. sh:maxCount 1 la hace mono-valuada.

Clase 5, diapositivas 19-20: «Cardinality constraints: minCount, maxCount.»
Usado en: P4, P10

6. sh:class — tipo del valor

Restringe que el valor de una propiedad pertenezca a una clase específica.

sh:property [
    sh:path dbo:affiliation ;
    sh:class dbo:University ;   # el objeto debe ser Universidad
]

A diferencia de sh:datatype (para literales), sh:class es para recursos/IRIs.

Clase 5, diapositiva 14: «sh:class ex:SoloArtist»

7. Qualified Shapes

sh:qualifiedValueShape + sh:qualifiedMinCount/sh:qualifiedMaxCount permiten contar cuántos valores cumplen una sub-shape, sin exigir que todos los valores la cumplan.

sh:property [
    sh:path dbo:affiliation ;
    sh:qualifiedValueShape [ sh:class dbo:University ] ;
    sh:qualifiedMinCount 1 ;   # al menos 1 valor es Universidad
]
Diferencia clave: sh:class exige que TODOS los valores sean del tipo. qualifiedValueShape solo exige que AL MENOS N valores lo sean. Las demás afiliaciones pueden ser empresas, ONGs, etc.
Usado en: P5

8. sh:equals — igualdad entre propiedades

Exige que dos propiedades tengan el mismo valor. Property Pair Constraint.

sh:property [
    sh:path dbp:dateOfBirth ;
    sh:equals foaf:birthday ;
]
Si una de las propiedades no está definida, la validación falla: «Must have same values as ...». Para manejar valores ausentes se necesita sh:or (ver P7).
Usado en: P6

9. Operadores lógicos: sh:or, sh:not

Permiten combinar condiciones con lógica booleana.

sh:or (
    [ sh:not [ sh:property [ sh:path dbp:dateOfBirth ; sh:minCount 1 ] ] ]
    [ sh:not [ sh:property [ sh:path foaf:birthday ; sh:minCount 1 ] ] ]
    [ sh:property [ sh:path dbp:dateOfBirth ; sh:equals foaf:birthday ] ]
)

La disyunción tiene 3 ramas: (1) dateOfBirth ausente → OK, (2) birthday ausente → OK, (3) ambos presentes e iguales → OK. Si ambos presentes y distintos → violación.

10. sh:pattern — expresiones regulares

Valida que un string coincida con una expresión regular.

sh:property [
    sh:path foaf:name ;
    sh:pattern "^[^\\d_]{2,}$" ;
]

La regex ^[^\d_]{2,}$ significa: sin dígitos (\d), sin guion bajo (_), mínimo 2 caracteres ({2,}).

Clase 5, diapositiva 18: «String Values: pattern.»
Usado en: P8

11. sh:in — valores enumerados

Restringe el valor a una lista cerrada de opciones.

sh:property [
    sh:path nobel:share ;
    sh:in ( "1" "2" "3" "4" ) ;
]

El valor debe ser exactamente uno de los listados.

Usado en: P9

12. Strings: minLength, maxLength, uniqueLang

Restricciones específicas para valores string.

sh:property [
    sh:path nobel:motivation ;
    sh:minLength 10 ;      # mínimo 10 caracteres
    sh:maxCount 1 ;        # máximo 1 valor por idioma
    sh:uniqueLang true ;   # no repetir idioma
]

sh:uniqueLang true asegura que no haya dos valores con el mismo language tag (ej. dos motivaciones en inglés).

Usado en: P10
