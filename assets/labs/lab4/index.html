1. SELECT-WHERE

Estructura básica de SPARQL. SELECT proyecta variables, WHERE contiene los patrones de grafo (triple patterns).

SELECT ?var1 ?var2 WHERE { ?s ?p ?o . }
Usado en todos los problemas.

2. Prefijos Wikidata

wd:Q232141 = entidad (Universidad de Chile). wdt:P31 = propiedad directa (instancia de). p:P166 = propiedad con calificadores. ps:P166 = valor de statement. pq:P585 = calificador.

wd:Q232141 wdt:P31 ?clase .          # Q232141 es instancia de ?clase
?persona wdt:P69 wd:Q232141 .         # estudió en UChile
?persona p:P166 ?stmt . ?stmt ps:P166 ?premio .  # premio con calificadores

3. SERVICE wikibase:label

Obtiene etiquetas legibles en el idioma solicitado. Agrega automáticamente variables ?xLabel por cada variable ?x.

SERVICE wikibase:label { bd:serviceParam wikibase:language "es,en". }
Sin este SERVICE, los resultados muestran Q-codes en vez de nombres legibles.

4. FILTER

Filtra resultados por condiciones booleanas. Operadores: <, >, =, !=, >=, <=, &&, ||, !.

FILTER (?fechaFundacion < ?fechaUCH)
FILTER (?otraU != wd:Q232141)

5. UNION

Combina resultados de dos o más patrones alternativos. Equivalente al OR lógico.

{ ?p wdt:P69 wd:Q232141. } UNION { ?p wdt:P108 wd:Q232141. }
Usado en P6, P7

6. BIND

Asigna una expresión a una variable. Útil para crear columnas calculadas o constantes.

BIND("estudiante" AS ?rol)
BIND(YEAR(NOW()) - YEAR(?fechaNacimiento) AS ?edad)
Usado en P6, P8

7. OPTIONAL

Hace que un patrón sea opcional: si no matchea, la variable queda sin valor (no se elimina la fila).

OPTIONAL { ?p wdt:P569 ?fechaNacimiento. }
OPTIONAL { ?p wdt:P19 ?lugar . ?lugar wdt:P17 ?pais. }
Usado en P7

8. Agregación: COUNT, AVG, GROUP BY

COUNT cuenta resultados. AVG calcula promedio. GROUP BY agrupa. ORDER BY ordena.

SELECT ?ocupacion (COUNT(?p) AS ?cantidad) WHERE {...} GROUP BY ?ocupacion ORDER BY DESC(?cantidad)
SELECT (AVG(?edad) AS ?promedio) WHERE {...}
Usado en P5, P8

9. Subqueries

Un SELECT anidado dentro de otro. La subquery se ejecuta primero y su resultado está disponible en la query externa.

SELECT ?p ?edad WHERE {
  { SELECT (AVG(?e) AS ?prom) WHERE {...} }   # subquery
  ?p wdt:P69 wd:Q232141 .                     # query externa
  FILTER (?edad > ?prom)
}
Usado en P8

10. FILTER NOT EXISTS

Verifica que un patrón NO exista en el grafo. Útil para comprobar ausencia de información (ej. personas sin fecha de muerte = vivas).

FILTER NOT EXISTS { ?p wdt:P570 ?fechaMuerte. }
En Wikidata, si una persona no tiene wdt:P570 (fecha de muerte), se asume viva. Esto puede ser impreciso para personas históricas sin dato registrado.
Usado en P8
